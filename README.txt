LAKE CITY SHINE EMPLOYEE PORTAL V1 PREVIEW
Start: login.html

For the demo, first open create-pin.html, enter Cole, and choose a 4–8 digit PIN.
Cole has Owner/Admin clearance.

This is a front-end prototype. Demo accounts/PINs use browser localStorage.
Do not use localStorage as the final live authentication system. The live version needs
secure backend authentication/database storage for employee PINs, clearance, photos,
issue reports, and supply requests.
